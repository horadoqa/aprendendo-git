Controle de versão

Git

Para começar a trabalhar com Git, configure seu ambiente de desenvolvimento e conheça os principais comandos utilizados no controle de versão.

Requisitos

No Windows, instale e configure os seguintes recursos antes de começar a trabalhar com Git.

Git

Sistema de controle de versão utilizado para acompanhar e gerenciar as alterações dos arquivos do projeto.

→

Git Bash

Terminal utilizado para executar comandos Git e outros comandos de linha de comando no Windows.

→

Visual Studio Code

Editor recomendado para desenvolver os arquivos do projeto e utilizar o Git através do terminal integrado.

→

GitHub

Plataforma utilizada para hospedar repositórios Git e colaborar com outros desenvolvedores.

→

Ambiente pronto?

Depois de instalar o Git e configurar seu ambiente, você estará pronto para criar seu primeiro repositório, registrar alterações e enviar seu projeto para um repositório remoto.
